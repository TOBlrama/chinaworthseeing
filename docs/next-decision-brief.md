# 下一轮决策简报

状态：建议，不是已确认规则

以下五项最适合在开始页面设计和 WordPress 选型前先确认。

## 1. 首发语言

建议：第一版先发布高质量英文内容，但内容模型、URL 和后台流程从一开始支持全部七种目标语言。

原因：

- 英文已被确定为默认主要语言
- 一次上线七种语言会显著增加翻译、核验和维护成本
- 先保证一种语言真正有用，比同时发布大量浅内容更符合项目原则

需要确认：是否接受“英文先上线，其余语言按市场优先级分批发布”。

## 2. 首发服务主张

必须从以下业务事实中选出一个清晰、可履约的首要承诺：

- 帮助规划中国旅行路线
- 提供旅行咨询
- 协调特定旅行服务
- 提供更完整的定制旅行方案

建议先选一个主服务作为首页核心 CTA，其余能力作为补充，不在早期同时承诺所有服务。

需要确认：当前团队可以稳定交付并愿意正式销售的服务是什么。

## 3. 询盘最小字段

建议首版采用：

- Name
- Where would you like to go?（多选）
- When are you planning to travel?
- Number of travelers
- WhatsApp country code + number
- Anything else you want us to know?（可选）
- 必要的隐私同意

预算、酒店等级、详细兴趣和每日安排留到 WhatsApp 沟通，以降低首次提交阻力。

需要确认：线索由谁接收、多久联系、保存在哪里，以及是否必须收集邮箱。

## 4. MVP 页面范围

建议的最小页面族：

- Home
- Destinations 与城市模板
- China Travel Guide 与文章模板
- Trip Planning 或 Services
- Plan My Trip 询盘页
- About / Why Us
- Contact、Privacy、Terms 与必要的法律信息

这只是信息架构起点，不代表首页具体结构已确认。

需要确认：路线内容是否作为独立页面族，以及首发是否需要展示价格。

## 5. 视觉方向

建议先确定三个形容词与两个反例，再生成完整视觉概念。

示例方法：

- 希望给人的感觉：可信、清晰、有本地洞察
- 明确避免：廉价团购感、过度传统符号堆砌

需要确认：品牌工作名称、目标价格感受，以及是否偏向编辑型旅行媒体、精品顾问或现代旅行服务。

## 建议的下一次产出

项目负责人确认以上五项后，下一份产出应是：

1. 一页式 MVP 产品简报
2. 站点地图与页面目标
3. 首页完整内容框架
4. 询盘流程线框
5. 可比较的 WordPress 技术方案

视觉概念应在这些内容明确后生成，并在编码前获得确认。
