# 首页首屏视觉概念 v1

状态：本地视觉实现已完成；公开文案与语言入口仍待确认  
确认日期：2026-08-10  
视觉稿：`homepage-hero-concept-v1.png`

## 1. 已确认的首屏结构

- 顶部使用独立的暖白色导航栏。
- 左侧显示网站名称；中间使用 Home、Inspirations、About、Contact 四个一级导航。
- 右侧预留语言入口和主要行动按钮。
- 导航下方使用接近满屏宽度和高度的大图 Hero。
- Hero 左侧使用深色渐变遮罩，保证白色文字在不同图片上都能清楚阅读。
- 文案区包含小型英文眉题、大型衬线标题、简短说明和两个行动按钮。
- Hero 背景由 8 张图片自动轮播。
- 轮播包含左右切换、8 个进度圆点以及暂停能力。

## 2. 建议的视觉参数

- 页面底色：暖白 `#F4EFE5`
- 主色：深森林绿 `#315F52`
- 正文深色：墨黑 `#1E211E`
- Hero 标题：高对比衬线字体，桌面端约 76–92px
- 导航与正文：干净的人文无衬线字体
- 导航高度：约 88px
- Hero 桌面高度：约 `calc(100vh - 88px)`，建议最小 680px
- 遮罩：左侧黑色约 75% 不透明度，向右渐变到透明
- 自动切换：每 5–6 秒一张，淡入淡出约 800ms
- 轮播：循环播放；鼠标悬停、键盘聚焦或用户操作时暂停

## 3. 图片交付规格

需要 8 张横向图片：

- 建议原图比例：16:9 或更宽
- 建议尺寸：至少 2400 × 1350px
- 最终网站格式：WebP 或 AVIF
- 最终单张文件建议不超过 350KB
- 主体尽量位于画面中部或右侧，左侧保留文字安全区
- 8 张图片的色温、对比度和摄影风格应尽量统一
- 优先选择真实游客体验、地标环境与人与目的地关系明确的照片
- 不使用来源不明、无法确认授权或带有第三方水印的图片
