建设顺序

  1. 确认业务与页面范围：先确定首发语言、公开服务、询盘字段和品牌方向。
  2. 选择主机：比较成本、访问地区、备份、测试站、迁移能力和技术支持。
  3. 建立测试环境：先在暂存站完成 WordPress 安装，正式域名暂不切换。
  4. 视觉概念确认：先看整页或分区设计，再进入正式页面开发。
  5. 实现内容模型与页面：搭建首页、目的地、指南、路线、服务说明和询盘入口。
  6. 接入表单和多语言基础：验证国家区号、错误提示、提交成功和线索去向。
  7. 上线前 QA：检查手机端、可访问性、性能、安全、SEO、隐私、备份与恢复。
  8. 连接正式域名：确认邮件 DNS 不受影响后，再修改 DNS 并启用 HTTPS。
购买主机前的最低检查：
当前 WordPress 官方建议主机支持 PHP 8.3+、MariaDB 10.11+ 或 MySQL 8.0+，并为每个安装启用 HTTPS。项目还应额外要求可导出、SFTP/SSH 或等效文件访问、数据库访问、自动备份与可验证恢复。

你与 Codex 的分工

你负责：业务取舍、预算、账户所有权、品牌与公开承诺的最终确认。

Codex 负责：研究对比、解释风险、制定结构、生成视觉概念、开发主题或功能、准备部署、执行技术检查并形成维护说明。

安全边界：不要把密码、支付信息或密钥发进项目文件。需要登录时优先由你在浏览器中登录，再由 Codex 在已登录状态下协助；改 DNS、购买服务和上线前会再次明确确认。
