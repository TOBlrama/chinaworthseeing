域名之后，网站还缺什么？

本课的胜利条件：你能说清域名、主机、WordPress 与 DNS 的区别，并知道下一步该准备什么。

把网站想成一家店：域名是门牌号，主机是店铺空间，WordPress 是陈列与管理系统，DNS 是把门牌号指向正确店铺的导航记录。
域名 Domain你已经拥有。它只是地址，不保存完整网站。
主机 Hosting保存 WordPress、图片和数据库，并对海外游客提供访问。
WordPress用于编辑页面、文章、导航、媒体和后台账号。
DNS通常在域名注册商处管理。上线时才把域名指向主机。

为什么不立刻修改域名？

因为网站应先在测试环境完成设计、内容和表单验证。提前切换域名只会让未完成页面公开，也可能误改现有邮箱使用的 DNS 记录。正式切换应放在上线流程末端。

这个项目的正确起点

先选择可迁移的 WordPress 主机，再建立测试站。按照 WordPress 当前官方要求，主机应支持 PHP 8.3+、MariaDB 10.11+ 或 MySQL 8.0+，并启用 HTTPS。本站还要特别关注海外访问、自动备份、恢复测试、暂存环境和数据导出。

Codex 能怎样参与？

你可以让我比较主机、规划页面、生成视觉概念、开发 WordPress 主题和表单、准备内容结构、检查速度与安全，并指导或协助部署。账户购买和重要业务承诺由你确认；凭据不要写入项目文件。

现在请准备 4 条信息

域名注册商、是否已买主机、每月主机预算、首要访客国家/地区。

把这四项告诉 Codex，即可进入下一课：主机选型与购买前检查。域名本身可以只给后缀或脱敏形式。
