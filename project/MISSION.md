# Mission: 与 Codex 协作搭建 WordPress 入境游网站

## Why
掌握如何把已购买的域名逐步变成一个可运营的 WordPress 网站，并能与 Codex 协作完成规划、设计、建设、上线和维护。最终目标是让海外游客获得可信的中国旅行信息、提交有效询盘，并进入 WhatsApp 人工沟通。

## Success looks like
- 能区分域名、DNS、主机、WordPress 和网站内容各自的作用
- 能向 Codex 提供完成下一阶段所需的信息，并理解哪些操作需要本人确认
- 能在 WordPress 后台安全地更新内容、查看询盘和执行基本维护
- 能验收网站的移动端、性能、安全、SEO、多语言与备份基础

## Constraints
- 使用 WordPress，英文为默认主要语言，并从最初结构考虑多语言扩展
- 第一阶段聚焦内容、信任、询盘、WhatsApp 沟通和成交，不建设复杂 OTA
- 技术方案必须可迁移、可维护、可扩展
- 主机、主题、插件和付费服务需先说明成本、替代方案与迁移风险，再确认

## Out of scope
- 第一阶段不学习或建设复杂会员、实时库存、复杂自动报价、微服务或 Kubernetes
- 不要求项目负责人先成为程序员再开始建设网站
