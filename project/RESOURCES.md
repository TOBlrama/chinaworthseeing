# WordPress 建站资源

## Knowledge

- [WordPress 官方：运行环境要求](https://wordpress.org/about/requirements/)
  用于核对主机是否提供当前建议的 PHP、数据库和 HTTPS 环境；购买主机前优先检查。
- [WordPress 官方：开始使用 WordPress](https://wordpress.org/documentation/article/get-started-with-wordpress/)
  WordPress 从规划、安装到后台设置的官方入门路线；用于理解完整建站顺序。
- [WordPress 官方：自动安装](https://wordpress.org/documentation/article/use-automated-installation/)
  介绍主机控制面板中的一键安装方式；用于主机开通后的首次安装。
- [WordPress 官方：备份](https://developer.wordpress.org/advanced-administration/security/backup/)
  说明文件与数据库备份、异地副本及恢复的重要性；用于设计上线和维护流程。
- [WordPress 官方：隐私工具](https://wordpress.org/documentation/article/wordpress-privacy/)
  说明 WordPress 自带的个人数据导出和删除工具及其边界；用于询盘数据与隐私流程设计。

## Wisdom (Communities)

- [WordPress.org 支持论坛](https://wordpress.org/support/forums/)
  官方社区支持入口；用于核对常见安装、主题和插件兼容问题。具体项目决策仍需结合本站需求验证。
